# إدارة الإعلانات

تظهر وحدة «إدارة الإعلانات | Advertising Management» في بوابة الإدارة المستقلة. المدير الرئيسي يملك الوصول تلقائياً؛ تُمنح صلاحية advertising للمدير الفرعي من حسابات المديرين.

- إضافة صورة رئيسية وصورة هاتف اختيارية، نص بديل، عنوان ووصف ورابط اختياري.
- اختيار الموضع: أعلى الرئيسية، بين التخصصات ومن نحن، قبل التذييل، أو صفحات الخدمات.
- الصور كاملة دون قص، داخل إطار ثابت النسبة: 16:5 للكمبيوتر و4:3 للهاتف.
- رفع JPG / PNG / WebP / AVIF حتى 5 MB مع تحسين WebP قبل الرفع إلى Blob الحالي.
- وقت العرض بالتوقيت المحلي لجهاز المسؤول، ويُحفظ UTC؛ البداية مشمولة والنهاية غير مشمولة.
- إعادة ترتيب بالسحب عبر المقبض أو أزرار التقديم والتأخير، مع حفظ تلقائي وحماية من تعارض الجلسات.
- التشغيل التلقائي ومدة العرض والانتقال ونوعه والأزرار والمؤشرات قابلة للتحرير.
- التفاعل يوقف الحركة، مع دعم RTL وتقليل الحركة ولوحة المفاتيح واللمس.

## التخزين والتحديث

تُحفظ advertisements وadvertising_config داخل payload الحالي في alhabib_cms_state باستخدام mutateCms ومعاملة الإصدار الحالية. لا توجد خدمة أو قاعدة بيانات جديدة أو ترحيل مدمر. لا تُضاف هاتان المجموعتان إلى API الجداول العام؛ جميع الكتابات تمر عبر API مخصص محمي بصلاحية advertising والتحقق من المصدر. يسجل سجل التدقيق عمليات الإدارة.

يقرأ الخادم الإعلانات النشطة قبل إخراج HTML. المكوّن يعيد null عند خلو الموضع: لا حاوية أو هامش أو بديل افتراضي. يبدأ النظام دون أي إعلان تجريبي. نهاية آخر إعلان تزيل القسم من الصفحة المفتوحة بمؤقت، ويُعاد جلب البيانات عند حدود الجدولة. البيانات تُحدّث أيضاً عند العودة إلى النافذة وكل 60 ثانية للصفحة المرئية فقط؛ تحديث الصفحة يجلب آخر حالة مباشرة. لذلك حذف إعلان أو تعطيله في تبويب إدارة مختلف يصل للتبويب المفتوح خلال 60 ثانية كحد أقصى في ظروف الاتصال الطبيعية، أو عند العودة إليه.

الحذف يزيل سجل الإعلان وروابطه من العرض. ملفات Blob لا تُحذف مادياً آلياً لأنها قد تكون مشتركة مع محتوى آخر؛ تبقى ضمن سياسة التخزين الحالية ولا تُستعمل كبدائل في العرض.

## التحقق

- node scripts/test-advertising.cjs: تشغيل معالجات API الفعلية بمخزن معزول، CRUD والصلاحيات والتعارض والروابط والجدولة والترتيب وإعدادات الحركة، وSSR حقيقي للتحقق من صفر عناصر HTML عند غياب إعلانات.
- tests/browser/advertising.spec.cjs: عرض متعدد، مؤقت انتهاء، تغييرات الحالة وإعادة الظهور، مقارنة موضع hero قبل/بعد الإخفاء، الهاتف وتقليل الحركة.
- فحوص المشروع الحالية وTypeScript وproduction build وPlaywright عبر GitHub Actions.
- اختبارات API الآلية معزولة ولا تثبت اتصال Neon/Blob الحي. قبل النشر النهائي يلزم اختبار رفع وحفظ وحذف بحساب إدارة في معاينة لها قاعدة مستقلة. لا تُعدّل بيانات الإنتاج لأغراض الاختبار.
